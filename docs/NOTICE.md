# MarkDown 작성시 주의사항

 * 수식은 $${수식}$$으로 작성한다.
 * in-line 수식은 ${수식}$으로 작성한다.
 * README.md 파일들의 양식은 가능한한 통일한다. (root README 제외)
 * 제목, 목록, 표는 GitHub Flavored Markdown을 따른다.
 * 실험 프로토콜과 비교 표는 `docs/exp/`에만 둔다.

# 코드 작성시 주의사항

 * 기존에 작성해 놓은 주석을 함부로 수정하지 않는다.
 * 신규 `.py` 파일 헤더는 기존 스타일을 따른다 (`# -*- coding: utf-8 -*-` 및 경로 주석).
 * `main.py`에 학습·샘플·시각화 로직을 몰아넣지 않는다.
 * 실험 하이퍼파라미터는 `configs/*.yaml`에 둔다.
 * 동작하는 주석 처리된 코드나 임시 디버그 출력을 커밋하지 않는다.
